# 小小醫院 2

給小朋友玩的溫和節奏醫院遊戲，[小小動物醫院](https://tsun-u.github.io/tsunu-hospital/) 的續作。

**線上玩：** https://tsun-u.github.io/tsunu-hospital-2/

## 玩法

- 病人在候診區排隊，玩家一個人同時當櫃台助理、護理師、醫生和藥師，把病人拖過四個站：**掛號 → 檢查 → 診間 → 藥局**
- 每個站的工具就在站裡，點一下就用：檢查台要用對工具才看得出該掛哪一科；七個分科診間（內科、耳鼻喉科、牙科、外科、中醫、獸醫、維修站）各有自己的醫生和治療工具；藥局照處方抓藥，一張處方可能有好幾種藥
- 病人頭上的泡泡永遠告訴你下一站去哪；到了醫生面前才揭曉病症，到了藥局才看到處方
- 幾個站可以同時進行：A 在檢查、B 在拿藥，互不干擾
- 人類病人為主，動物會來看獸醫，機器人會來維修站
- **零失敗**：病人永遠不會離開，等太久只會哭哭，點一下拍拍就好；拖錯站會回到原來的地方、按錯工具只會搖搖頭，不扣分
- 一天一班，看完當天的病人就下班結算；下班後醫院會休息幾分鐘讓眼睛休息，倒數完再開診
- 隨天數解鎖新診間、新病人；醫院手冊三個分頁：患者名冊記來過幾次、醫生名冊看哪些科開診了、病症卡把「檢查 → 科別 → 治療 → 藥」整條線畫出來，治好過才點亮
- 背景音樂兩首：看診時是輕快的 8bit 曲，休診時換成溫和的音樂盒曲；頂列的音符鈕可以單獨關掉音樂，喇叭鈕管音效

## 語言

介面支援中文與台文（台語漢字＋台羅），用頂列的語言鈕切換。

## 技術

- 零建置單檔：`index.html`＋`data.js`（資料表）＋`strings.js`（字串）＋`assets/`（WebP 圖檔）
- 觸控優先，橫向平板為主；支援加到主畫面（`manifest.json`）
- 進度存在瀏覽器的 localStorage，沒有帳號、沒有網路需求
- 美術由 gpt-image-2 生成、人工逐張驗收；解鎖星星動畫用 lottie-web
- 背景音樂與音效全部用 Web Audio 即時合成，沒有音檔：`audio.js` 是規則式作曲器（固定種子產生固定旋律）加排程器，編曲心法參考 AMIX 的 EASY 8BIT EDITOR 公開說明，實作原創
- 字體：jf open 粉圓 2.1 的子集，依 OFL 授權改名為 Tsunu Round（見 `fonts/LICENSE-OFL.txt`）
